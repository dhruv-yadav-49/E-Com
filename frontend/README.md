# ShopZen Frontend | React + Vite

This is the frontend repository for **ShopZen**, a premium e-commerce platform. It is built using React and styled with Tailwind CSS to provide a modern, fast, and responsive user experience.

## 🚀 Key Technologies
- **React 18**
- **Vite** (Build Tool)
- **Tailwind CSS** (Styling)
- **Framer Motion** (Animations)
- **Axios** (API Requests)

## 🛠️ Development
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

## 📦 Build
To create a production-ready build:
```bash
npm run build
```
